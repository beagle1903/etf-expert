# Working agreement

Build a simple local ETF research tool. Early phases use Python scripts and local files. No GUI, Docker, agent framework, in-app LLM, or harness subagents. Work directly without delegation.

Prove real data coverage before adding portfolio construction. Keep candidate universe size separate from portfolio size. Preserve source and collection dates, missing values, errors and exclusions. Do not shrink the universe silently or treat missing evidence as a pass. Legal identity and economic exposure are separate questions.

Use focused verification appropriate to each change. Report live observations separately from offline tests. Add dependencies and infrastructure only for a demonstrated need. Do not recreate the archived project's workflow machinery.
